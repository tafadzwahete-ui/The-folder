# Simple Python Calculator
 Description

This is a simple calculator program built with Python that runs in the command line. It helps you perform basic math operations like adding, subtracting, multiplying, and dividing numbers.

Features

With this calculator, you can:

Add two numbers together
Subtract one number from another
Multiply two numbers
Divide one number by another
Avoid errors when trying to divide by zero

# How It Works

When you run the program, it shows you a menu with different options.
You choose the operation you want (from 1 to 4), then enter two numbers.
The calculator will process your input and display the answer.

# Code Structure

The program is organized into simple functions:

add(a, b) → adds two numbers
subtract(a, b) → finds the difference
multiply(a, b) → multiplies the numbers
divide(a, b) → divides the numbers and checks for division by zero

 ###Guess the Number – Python Program###
 Description

This is a small and fun beginner Python program. The idea is simple: the computer has a secret number, and you keep guessing until you get it right.

It’s a great way to practice how loops and conditions work in Python.

# How It Works
The program sets a secret number (password = 7).
You are asked to guess the number.
If your guess is correct → it tells you "correct".
If your guess is wrong → it says "wrong" and lets you try again.

The program keeps running until you stop it manually.


#How to Run
Make sure Python is installed on your computer.

Save the code in a file called:

guess_game.py

Open your terminal or command prompt and run:

python guess_game.py
